# Rock-Paper-Scissors Console Game (C++)

A classic console-based **Rock-Paper-Scissors** game developed in **C++**, applying structured programming principles, clean modular functions, enumerations (`enum`), and structures (`struct`) to manage game states, rounds, and final results.

---

## Features

- **Customizable Rounds:** Choose how many rounds you want to play (from 1 to 10 rounds) per session.
- **Interactive Gameplay:** Play directly against a randomized computer opponent.
- **Dynamic Console Feedback:** Screen colors and sound alerts change dynamically based on each round's outcome:
  - **Green Screen:** Player wins the round.
  - **Red Screen + Bell Alert:** Computer wins the round.
  - **Yellow Screen:** Round ends in a draw.
- **Detailed Round & Final Scoreboard:** Displays individual round choices, round winner, and a comprehensive final game summary.
- **Replayability:** Option to immediately start a new game session without restarting the application.

---

## Technologies Used

- **Language:** C++
- **IDE:** Microsoft Visual Studio 2022
- **Core Concepts:** Procedural programming, `enum`, `struct`, and modular functions.

---

## How to Run

1. Open the solution file (`.sln`) in **Visual Studio 2022**.
2. Press **`Ctrl + F5`** to build and run the game.
